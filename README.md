# MenuPro — Restaurant Menu Management System

**Task ID:** WD-RES-004  
**Student Code:** DAS-RES-004  
**Company:** Data Alcott Systems

MenuPro is a responsive front-end demo for restaurant menu management, built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Dashboard with sample menu and inventory indicators
- Category management (add and delete categories)
- Menu item management (add, edit, delete, search and filter)
- Customer-facing digital menu with category filters
- Pricing management with special-offer prices
- Ingredient inventory with stock thresholds and updates
- Sample analytics dashboard
- CSV exports for menu catalogue and inventory
- Light/dark mode
- Browser localStorage persistence
- Responsive desktop and mobile layout

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Push the files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for deployment and open the published Pages URL.

## Notes and limitations
- This is a front-end demonstration. It does not use a server database.
- Analytics and initial menu/inventory values are illustrative sample data.
- The admin profile is a demo; there is no real authentication.
- Inventory does not automatically deduct ingredients from sales.
- Data stored in localStorage is specific to the browser and device.
